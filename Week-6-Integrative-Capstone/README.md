This project represents the final integrative capstone of the YUVA Data Science Internship. It brings together the complete Data Science workflow developed throughout the six-week internship using a Gurugram Real Estate dataset.

The project begins with data acquisition, cleaning, preprocessing, and feature preparation, followed by Exploratory Data Analysis (EDA) to understand property prices, areas, property types, BHK configurations, RERA approval, property status, and other important market characteristics.

The project then applies Unsupervised Learning techniques for real-estate market segmentation. K-Means Clustering and Hierarchical Clustering are implemented and evaluated using Silhouette Score, Davies-Bouldin Index, and Calinski-Harabasz Index. K-Means is selected as the better-performing clustering approach, and the resulting clusters are interpreted to identify distinct property segments.

The next stage focuses on Supervised Machine Learning for real-estate price prediction. Multiple regression models, including Linear Regression, Random Forest, and Gradient Boosting, are trained and evaluated using MAE, RMSE, R², and cross-validation. Random Forest provides the strongest supervised-learning performance and is selected as the final machine-learning model.

The project also applies Deep Learning using an Artificial Neural Network (ANN) for property price prediction. The neural network uses numerical and categorical property features after appropriate preprocessing and includes Dense layers, ReLU activation, Dropout regularization, Adam optimization, Mean Squared Error loss, and Early Stopping. Multiple target-scaling experiments are performed, with the scaled-target model achieving the best neural-network performance.

The capstone integrates the results of data preprocessing, EDA, clustering, machine learning, and deep learning into one end-to-end Data Science workflow. It also discusses model comparison, practical real-estate insights, limitations, challenges such as data quality and computational constraints, and possible future improvements.

Technologies & Tools: Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow/Keras, Jupyter Notebook.

Key Areas Covered: Data Cleaning • EDA • Data Visualization • Feature Engineering • Unsupervised Learning • K-Means Clustering • Hierarchical Clustering • Supervised Learning • Regression • Random Forest • Gradient Boosting • Artificial Neural Networks • Model Evaluation • Business Insights

This capstone demonstrates the practical application of the complete Data Science lifecycle to a real-world real-estate prediction and segmentation problem.
