# Week 2 – Exploratory Data Analysis and Visualization

## Internship
YUVA Internship – Data Science using Python

## Objective
The objective of Week 2 was to perform Exploratory Data Analysis (EDA)
and visualization on the real estate dataset to identify patterns,
relationships, trends, and anomalies.

## Analysis Performed
- Univariate analysis
- Bivariate analysis
- Correlation analysis
- Outlier and anomaly analysis
- Grouped and aggregated analysis

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Deliverables
- Jupyter Notebook
- Cleaned Real Estate Dataset
- Week 2 Internship Report
