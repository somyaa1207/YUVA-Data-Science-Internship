# Week 1 – Data Cleaning

## Internship
YUVA Internship – Data Science using Python

## Objective
The objective of Week 1 was to clean and preprocess a real estate dataset
to make it suitable for Exploratory Data Analysis and further analysis.

## Work Performed
- Removed duplicate records
- Standardized column names
- Corrected column naming inconsistencies
- Converted numerical columns into appropriate data types
- Standardized categorical values
- Converted RERA approval values into Boolean format
- Checked missing values and data types
- Prepared the cleaned dataset for Week 2 EDA

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Deliverables
- Jupyter Notebook
- Cleaned Real Estate Dataset
- Week 1 Internship Report
